## ✦ AI 课表助手 · 自然语言调度

> **🗣️ 对话演示**  
> **同学**：“帮我查查这周五下午有没有课？另外提醒我下周二考离散数学。”  
> **余课助手**：“✦ 课表已检索完毕。周五下午 14:00 - 15:35 为【大学物理实验】（实验楼 302），之后暂无课程安排。已为你新建考试倒计时【离散数学期末考】，设为下周二并开启提前 1 天提醒。”  
> *(动作需本地自检通过，用户点击确认后方落库写入数据库)*

课表页头常驻「✦ 助手」面板，用日常语言即可自如操控课表与日程：

- 💬 **自然语言即时对话**：「这周五下午哪节最空？」、「把第 3-5 周的高数换到周二第二大节」、「提醒我下周二考离散数学」。
- 🛡️ **先查再改，多轮工具调用**：智能体通过严格的只读工具检索当前课表，杜绝凭空编造。
- 📋 **先预览、再落库**：动作会以清晰的对比卡片（`改前 → 改后`）呈现，用户亲手点击「确认执行」才写入数据库。
- ⚙️ **开放模型生态**：自由配置 Google Gemini 或任意 OpenAI 兼容服务（DeepSeek、Kimi、通义千问、智谱 GLM 等），密钥仅保存在本机。
- 🤖 **系统级智能体互联（AppFunctions，Android 16+）**：课表能力标准化开放给系统端侧智能体调用。

## 🎨 设计哲学：东方「余白（Yohaku）」

应用遵循 **Yohaku（余白）** 的设计取向 —— **把课表当纸看，不把界面当装饰**：

1. **一抹强调色**：强调色仅出现于正在进行的课程与当前焦点状态，全屏视觉焦点不超过 5%。
2. **三档中性色阶**：纸面色浅深双套，暖纸色相自然温和，层级全由明度自然铺叙。
3. **课程低饱和专属淡彩**：每门课新建或导入时被赋予专属低饱和和色底彩，扫视即辨识，同课同色。
4. **余者尽留为白**：空堂之处绝不堆砌插画或广告，留白本身便是最好的信息反馈。
5. **典雅衬线排版**：内置思源宋体与等宽字体，节次数字与文字呼吸对齐。

## 📱 桌面小组件与个性图标

- **今日课表（4×2）**：当日课程清晰铺陈，当前上课高亮显示。
- **明日课程（2×2）**：前瞻明日安排，备课出行心中有数。
- **下节课（1×1）**：极致紧凑，显示下一门课的时间与教室地点。
- **日程看板（4×2）**：待办事项与倒计时混合时间线，直观标注剩余天数。
- **9 款角色表情图标**：桌面上清新的蓝发角色拥有 9 种喜怒哀乐生动表情，支持随心手动切换或设置「每次打开/每小时/每天」自动轮播。

## 🔒 隐私与安全性承诺

- **数据绝对本地优先**：课表、日程、设置默认存储于手机本地 Room 数据库。不注册账号亦享有完整功能。
- **云同步安全透明**：登录后仅在多端同步课程与日程，支持软删除防复活机制；可随时在设置中清除远端数据。
- **凭据零泄露保证**：教务系统与雨课堂登录均在受控隔离的本地会话中完成，教务密码绝不入库，会话凭据加密存放。
- **AI 图片端到端直连**：AI 图片识别直接经由您配置的 API Key 走加密信道发送至对应服务商，不经由任何第三方中间服务器。
- **无追踪无广告**：不植入任何商业推广、开屏弹窗或第三方广告 SDK。

## ❓ 常见问题

<details>
<summary><b>Q: 提醒没有按时响或者被系统杀掉？</b></summary>
<p>国产定制系统（如 HyperOS、MagicOS、ColorOS、OriginOS）后台保活机制较为激进。请前往应用内「设置 → 提醒 → 提醒可靠性」，按照机型引导开启<b>通知权限、精确闹钟、电池无限制白名单及自启动权限</b>。开齐后即可稳定准时唤醒。</p>
</details>

<details>
<summary><b>Q: 课程颜色可以自由调整吗？</b></summary>
<p>完全支持！课表自动分配的低饱和色彩确保了视觉和谐且互不冲突。若需自定义，可在「设置 → 课表 → 课表显示 → 配色方案」中切换（柔和 / 标准 / 丰富），亦可点击单门课程的编辑页面，从 20 种东方和色预设中挑选，或直接输入自定义十六进制色值（#RRGGBB）。</p>
</details>

<details>
<summary><b>Q: 我的学校没有出现在教务列表里？</b></summary>
<p>您可以尝试以下方案：<br/>
1. <b>AI 截图导入</b>：截一张教务课表图，交由 AI 秒级解析；<br/>
2. <b>表格导入</b>：复制教务网页表格或选择 Excel 文件导入；<br/>
3. <b>通用教务入口</b>：若学校使用主流教务系统（如正方、青果等），可填入教务地址尝试通用脚本解析。</p>
</details>

<details>
<summary><b>Q: 更换新手机后，如何迁移课表数据？</b></summary>
<p>在原手机上进入「设置 → 账号与数据」登录账号完成一次同步，在新设备上登录同一账号即可瞬间拉取完整课表与日程安排。</p>
</details>

## 🛠️ 开发者指南

欢迎共同参与余课的打磨与建设！

```bash
# 克隆仓库
git clone https://github.com/kuailiaojie/classtable.git
cd classtable

# 构建调试版本（产出按架构拆分的 APK 及 Universal 包）
./gradlew assembleDebug

# 构建发布版本
./gradlew assembleRelease
```
